SwipeSelection Reborn

A modern rebuild of SwipeSelection for iOS 16+. Swipe the keyboard to move the caret, and swipe from Shift or Delete to select text.

Version 1.0.0 com.zoot334.swipeselectionreborn

Compatibility

Build Architecture Compatibility
RootHide iphoneos-arm64e iOS 16+ · RootHide
Rootless iphoneos-arm64 iOS 16+ · rootless build (not independently tested)

Tested on iOS 16 (palera1n, RootHide) and iOS 18 (Dopamine 3, RootHide).

Features

  • Swipe left or right to move the caret.
  • Swipe from Shift or Delete to extend a selection.
  • Apple’s native trackpad-style keyboard fade.
  • Optional haptics in five strengths.
  • Cursor speed slider with a center snap and precise value entry.
  • Optional Space, Shift & Delete only activation mode.
  • WebKit and CodeMirror text-field support.

Activation mode

When Space, Shift & Delete Only is enabled, only swipes that start on those keys control SwipeSelection. Swipes from other keys follow your existing Apple Slide to Type setting. SwipeSelection does not change that setting.

Install

  1. Download the matching deb:
    • RootHide: iphoneos-arm64e
    • Rootless: iphoneos-arm64
  2. Install with Sileo, Zebra, or Filza.
  3. Respring if the Settings pane or keyboard does not reload automatically.
